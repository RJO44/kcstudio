# Company Static Site

## Cara jalanin
- Buka index.html langsung di browser, atau
- Pakai Live Server (VSCode) agar reload otomatis.

## Ganti gambar karakter
- Replace file di:
  assets/img/characters/character-1.svg dst
- Boleh pakai PNG/JPG/SVG.
- Pastikan nama file sama atau update path di index.html.

## Kustomisasi
- Warna di CSS: :root variabel theme.
- Konten: edit langsung di index.html.
